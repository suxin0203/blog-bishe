# 数据库表名修复记录

> 修复时间：2026-05-14
> 修复范围：Express 后端代码中遗漏的 `wz_` 表名前缀

---

## 修复背景

博客系统数据库表名从普通命名（如 `users`）升级为带前缀命名（如 `wz_users`），但部分代码未同步更新，主要集中在小程序登录、绑定、授权相关接口。

---

## 修复的文件

### 1. controllers/wechatlogin.js

**修复位置**：第 35 行

**修复内容**：
```javascript
// 修复前
const sql = `SELECT * FROM users WHERE openid = ?`;

// 修复后
const sql = `SELECT * FROM wz_users WHERE openid = ?`;
```

**影响接口**：
- `GET /wechat/userinfo/:openid` - 微信登录根据 openid 获取用户信息

## 注意事项

1. **小程序开发**：现在可以正常调用所有用户相关接口，表名已统一为 `wz_users`
2. **数据库迁移**：如果数据库中表名还是旧的，需要执行表重命名 SQL
3. **后续开发**：新增 SQL 语句时，务必使用 `wz_` 前缀
