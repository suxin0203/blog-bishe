# 第3章 系统设计

## 3.1 架构设计

文栈博客系统采用前后端分离架构，前端与后端独立开发、独立部署，通过 RESTful API 进行数据交互。整体分为三层：表现层（前端）、业务逻辑层（后端）、数据持久层（数据库）。

**表现层**：基于 Vue 3 + Vite 构建单页面应用，通过 Axios 与后端交互，部署于 Nginx/CDN。

**业务逻辑层**：基于 Node.js + Express 构建，采用四层分层架构——路由层（routes）负责请求分发，控制器层（controllers）负责参数校验与响应组装，服务层（services）负责业务逻辑，数据访问层通过 mysql2 操作数据库。

**数据持久层**：MySQL 8.0 存储全部业务数据，mysql2 连接池管理连接。

系统请求处理流程：请求到达 Express 后依次经过 CORS 中间件、时间戳校验中间件（防重放）、Multer 文件处理、Morgan 日志、JWT 鉴权中间件，最终由路由分发至控制器，控制器调用服务层完成业务，返回统一格式 `{ code, message, data }`。

前端 Axios 拦截器统一处理：每次请求注入 `X-Request-Time` 时间戳和 `Authorization: Bearer <token>`；响应时检测业务 401 自动调用 `/users/refresh` 换取新 token 并重发原请求。

## 3.2 功能模块设计

系统划分为八个功能模块，各模块职责独立，通过数据库关联协作。

| 模块 | 主要职责 | 涉及数据表 |
|------|---------|----------|
| 用户认证模块 | 注册、登录、找回密码、Token管理、用户CRUD | wz_users |
| 文章管理模块 | 文章CRUD、状态管理、搜索、归档、阅读量统计 | wz_articles、wz_article_tags |
| 评论系统模块 | 评论发表、敏感词过滤、楼中楼、审核管理 | wz_comments |
| 分类标签模块 | 分类CRUD、标签CRUD、多维度归档筛选 | wz_categories、wz_tags、wz_article_tags |
| 互动模块 | 文章点赞、文章收藏、积分联动 | wz_article_likes、wz_article_favorites |
| 积分商城模块 | 积分获取、商品管理、兑换订单、积分流水 | wz_points_log、wz_points_items、wz_points_orders |
| 系统设置模块 | 站点配置、主题、敏感词、轮播图、友链、留言 | wz_otherswitch、wz_swiper、wz_friendslink、wz_messages |
| 数据看板模块 | 统计数据聚合、ECharts可视化 | 聚合查询各业务表 |

**角色权限设计**：系统设计三种角色，权限如下：

| 功能 | 管理员 | 编辑 | 普通用户 |
|------|--------|------|--------|
| 用户管理 | 全部 | 无 | 仅修改自身 |
| 文章管理 | 全部 | 仅自己文章 | 无 |
| 评论/分类/标签管理 | 全部 | 全部 | 无 |
| 系统设置 | 全部 | 无 | 无 |
| 数据看板 | 全部 | 全部 | 无 |
| 点赞/收藏/积分兑换 | 支持 | 支持 | 支持 |

## 3.3 数据库设计

### 3.3.1 数据关系设计

系统数据库包含 15 张数据表，主要关联关系如下：

- wz_users → wz_articles（一对多，author_id）
- wz_articles → wz_categories（多对一，category_id）
- wz_articles ↔ wz_tags（多对多，通过 wz_article_tags）
- wz_articles → wz_comments（一对多，article_id）
- wz_comments 自关联（parent_id，楼中楼）
- wz_users → wz_article_likes / wz_article_favorites（记录互动行为）
- wz_users → wz_points_log（积分流水）
- wz_points_items → wz_points_orders（商品与订单）

### 3.3.2 数据库表设计

**wz_users（用户表）**

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INT PK AUTO_INCREMENT | 用户ID |
| username | VARCHAR(50) UNIQUE NOT NULL | 账号 |
| password | VARCHAR(255) NOT NULL | 密码（bcrypt）|
| nickname | VARCHAR(50) | 昵称 |
| avatar | VARCHAR(255) | 头像URL |
| email | VARCHAR(100) | 邮箱 |
| role | VARCHAR(20) DEFAULT 'user' | 角色 |
| is_root | TINYINT DEFAULT 0 | 超级管理员标识 |
| points | INT DEFAULT 0 | 积分 |
| last_login_at | DATETIME | 最后登录时间 |
| created_at | DATETIME | 注册时间 |

**wz_articles（文章表）**

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INT PK AUTO_INCREMENT | 文章ID |
| title | VARCHAR(200) NOT NULL | 标题 |
| summary | TEXT | 摘要 |
| cover | VARCHAR(255) | 封面图URL |
| content | LONGTEXT | 正文（HTML）|
| status | TINYINT DEFAULT 0 | 0正常/1置顶/2回收站 |
| category_id | INT FK | 分类ID |
| author_id | INT FK | 作者ID |
| view_count | INT DEFAULT 0 | 总阅读量 |
| view_internal_count | INT DEFAULT 0 | 站内阅读量 |
| view_external_count | INT DEFAULT 0 | 站外阅读量 |
| like_count | INT DEFAULT 0 | 点赞数 |
| favorite_count | INT DEFAULT 0 | 收藏数 |
| comment_count | INT DEFAULT 0 | 评论数 |
| created_at | DATETIME | 发布时间 |

**wz_comments（评论表）**

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INT PK AUTO_INCREMENT | 评论ID |
| article_id | INT FK NOT NULL | 所属文章 |
| user_id | INT FK | 评论用户 |
| content | TEXT NOT NULL | 评论内容（已过滤）|
| parent_id | INT FK | 父评论ID（楼中楼）|
| status | TINYINT DEFAULT 0 | 0待审核/1通过/2屏蔽 |
| created_at | DATETIME | 评论时间 |

**wz_categories（分类表）**

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INT PK AUTO_INCREMENT | 分类ID |
| name | VARCHAR(50) NOT NULL | 分类名称 |
| description | VARCHAR(255) | 描述 |
| created_at | DATETIME | 创建时间 |

**wz_tags（标签表）**

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INT PK AUTO_INCREMENT | 标签ID |
| name | VARCHAR(50) UNIQUE NOT NULL | 标签名称 |
| created_at | DATETIME | 创建时间 |

**wz_article_tags（文章标签关联表）**

| 字段 | 类型 | 说明 |
|------|------|------|
| article_id | INT FK NOT NULL | 文章ID |
| tag_id | INT FK NOT NULL | 标签ID |

**wz_article_likes（点赞表）**

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INT PK AUTO_INCREMENT | 记录ID |
| user_id | INT FK NOT NULL | 用户ID |
| article_id | INT FK NOT NULL | 文章ID |
| created_at | DATETIME | 点赞时间 |

**wz_article_favorites（收藏表）**：结构同点赞表，记录用户收藏关系。

**wz_points_log（积分流水表）**

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INT PK AUTO_INCREMENT | 记录ID |
| user_id | INT FK NOT NULL | 用户ID |
| amount | INT NOT NULL | 积分变动（正/负）|
| type | VARCHAR(50) | 类型（login/like/exchange）|
| description | VARCHAR(255) | 说明 |
| created_at | DATETIME | 时间 |

**wz_points_items（积分商品表）**

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INT PK AUTO_INCREMENT | 商品ID |
| name | VARCHAR(100) NOT NULL | 商品名称 |
| description | TEXT | 商品描述 |
| price | INT NOT NULL | 所需积分 |
| stock | INT DEFAULT 0 | 库存 |
| image | VARCHAR(255) | 商品图片 |
| status | TINYINT DEFAULT 1 | 0下架/1上架 |
| created_at | DATETIME | 上架时间 |

**wz_points_orders（积分订单表）**

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INT PK AUTO_INCREMENT | 订单ID |
| user_id | INT FK NOT NULL | 用户ID |
| item_id | INT FK NOT NULL | 商品ID |
| points_cost | INT NOT NULL | 消耗积分 |
| status | VARCHAR(20) DEFAULT 'pending' | 订单状态 |
| created_at | DATETIME | 下单时间 |

**wz_otherswitch（系统设置表）**

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INT PK | ID |
| site_name | VARCHAR(100) | 站点名称 |
| site_description | TEXT | 站点描述 |
| site_logo_url | VARCHAR(255) | LOGO图片URL |
| darkthem | TINYINT | 深色主题开关 |
| footer_title | VARCHAR(100) | 页脚标题 |
| footer_content | TEXT | 页脚内容 |

| sensitive_words | TEXT | 敏感词（逗号分隔）|

**wz_messages（留言表）**：存储用户留言内容、用户信息、审核状态、留言时间。

**wz_friendslink（友情链接表）**：存储友链名称、URL、图标、描述、排序。

**wz_swiper（轮播图表）**：存储轮播图图片URL、跳转链接、排序、启用状态。
