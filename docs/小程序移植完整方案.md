# 小程序移植完整方案

> 本文档整合了小程序移植计划、推荐技术栈和页面原型设计，提供完整的小程序开发指南。

---

## 一、移植目标与优先级

### 1.1 移植目标

- 提供移动端文章阅读体验
- 复用现有账号体系，支持微信身份绑定
- 展示积分系统，支持积分查看和兑换
- 作为 PC 扫码登录的确认端
- 展示多端协同能力

### 1.2 功能优先级

**P0（MVP）**：
- 首页文章流、文章列表、文章详情
- 微信登录、用户中心
- 积分余额展示、积分流水

**P1（增强）**：
- 评论列表与发表、点赞收藏
- 我的收藏、积分商城

**P2（展示）**：
- PC 扫码登录确认、文章分享

## 二、推荐技术栈

### 2.1 核心技术

| 层级 | 推荐方案 | 理由 |
|------|----------|------|
| **框架** | 微信小程序原生 | 性能最优、体积小、审核通过率高 |
| **UI 组件** | Vant Weapp | 组件丰富、文档完善、适合快速开发 |
| **文章渲染** | mp-html（MVP）<br/>Towxml（长期） | HTML 兼容现有数据<br/>Markdown 更适合小程序 |
| **状态管理** | globalData + Storage | 简单够用，无需引入额外库 |
| **请求封装** | 自封装 request.js | 统一处理 Token、超时、错误 |

### 2.2 技术栈总览

```
微信小程序原生框架
├── Vant Weapp（UI 组件）
├── mp-html（HTML 渲染）
├── request.js（请求工具）
└── globalData + Storage（状态管理）
```

## 四、核心功能实现

### 4.1 微信登录流程

```
用户打开小程序
→ wx.login 获取 code
→ 后端换 openid
→ 判断是否已绑定
→ 已绑定：签发 Token，直接登录
→ 未绑定：展示注册/绑定入口
```

**关键接口**：
- `GET /wechat/openid/:code` - 获取 openid
- `GET /wechat/userinfo/:openid` - 查询绑定用户
- `POST /users/register` - 注册新账号
- `POST /users/login` - 绑定已有账号

### 4.2 文章浏览

**接口复用**：
- `GET /articles` - 文章列表
- `GET /articles/top` - 热门文章
- `GET /articles/:id` - 文章详情
- `POST /articles/:id/view` - 阅读量增加
- `GET /categories` - 分类列表
- `GET /tags` - 标签列表

**渲染方案**：
- MVP 阶段：使用 `mp-html` 渲染现有 HTML
- 长期方案：迁移到 Markdown，使用 `Towxml` 渲染

### 4.3 积分系统

**接口复用**：
- `GET /users/me` - 用户信息（包含积分）
- `GET /points/log` - 积分流水
- `GET /points/goods` - 商品列表
- `POST /points/orders` - 创建兑换订单

**页面设计**：
- 积分首页：当前积分、今日登录、快捷入口、最近记录
- 积分流水：按时间倒序展示，支持筛选
- 积分商城：商品列表、详情、兑换

### 4.4 扫码登录确认

**流程**：
```
小程序扫描 PC 端二维码
→ 解析 sessionId
→ 展示设备信息（浏览器、IP）
→ 用户确认登录
→ 后端更新会话状态
→ PC 端轮询获取 Token
```

**接口**：
- `POST /qr-login/entry` - 扫码入口
- `POST /qr-login/register-and-confirm` - 注册并确认
- `POST /qr-login/bind-and-confirm` - 绑定并确认

## 九、风险与注意事项

### 9.1 技术风险

- HTML 渲染兼容性：使用 mp-html，测试常见标签
- Token 过期处理：实现自动刷新机制
- 图片加载慢：使用懒加载、压缩图片

### 9.2 审核风险

- 内容安全：评论审核、敏感词过滤
- 用户隐私：明确隐私政策、最小化权限
- 功能合规：避免诱导分享、虚拟支付

### 9.3 性能优化

- 文章列表使用分页加载
- 图片使用 CDN 加速
- 避免频繁 setData
- 使用 wx:key 优化列表渲染
