# 文栈博客系统的设计与实现

---

## 摘要

随着互联网内容的持续增长，个人与团队对博客平台的需求日益增加。然而，现有不少博客系统在权限划分、数据可视化以及用户互动闭环等方面存在不足，难以兼顾内容管理效率与读者体验。在此背景下，本研究旨在设计并实现一套前后端分离的博客系统——文栈博客，以提升内容发布、管理与互动的整体水平。

在技术层面，前端采用 Vue 3、Vite、Naive UI 等构建用户界面，后端采用 Node.js、Express 与 MySQL 实现业务逻辑与数据持久化，并结合 JWT、bcrypt、ECharts 等技术完成认证、加密与数据可视化。系统实现了用户注册与登录、文章创建与分类标签及时间归档、评论发表与敏感词过滤及人工审核、系统设置与主题切换、数据看板与流量统计、积分与积分商城、收藏与点赞、友情链接与留言板等功能模块；具备前后端分离、Token 自动刷新、时间戳防重放、角色权限控制等特色。

文栈博客系统较好地满足了个人或团队在博客发布、互动与运营可视化等方面的需求，为轻量级博客系统的设计与实现提供了可参考的解决方案。

**关键词：** 博客系统；内容管理；Vue 3；Express；MySQL

---

## Abstract

With the continuous growth of online content, the demand for blog platforms from individuals and teams has been increasing. However, many existing blog systems lack fine-grained permission control, data visualization, and a closed loop of user interaction, making it difficult to balance content management efficiency and reader experience. Against this background, this study aims to design and implement a front-end and back-end separated blog system, Wenzhan Blog, to improve the overall level of content publishing, management, and interaction.

At the technical level, the front end uses Vue 3, Vite, and Naive UI to build the user interface, while the back end uses Node.js, Express, and MySQL to implement business logic and data persistence, combined with JWT, bcrypt, and ECharts for authentication, encryption, and data visualization. The system implements user registration and login, article creation with categories and tags and time-based archiving, comment posting with sensitive-word filtering and manual review, system settings and theme switching, a data dashboard and traffic statistics, points and a points mall, favorites and likes, friend links and a message board, and other functional modules. It features front-end and back-end separation, token auto-refresh, timestamp anti-replay, and role-based access control.

The Wenzhan Blog system meets the needs of individuals or teams for blog publishing, interaction, and operation visualization, and provides a referable solution for the design and implementation of lightweight blog systems.

**Keywords:** Blog system; Content management; Vue 3; Express; MySQL
