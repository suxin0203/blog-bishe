## 4.2 功能模块实现

### 4.2.1 用户认证模块

**注册**：接口 `POST /users`，依次执行图形验证码校验（MD5哈希比对，一次性消费）、账号格式校验（≥4位）、密码强度校验（含字母与数字）、账号唯一性校验，通过后 bcrypt 加密（saltRounds=10）密码写入 wz_users 表。

图形验证码由 `GET /users/captcha` 生成，返回 captchaId 与 SVG 图片，答案存于服务端内存 Map，5分钟过期，提交时 MD5 哈希比对后即删除防止复用。

**登录与 Token 签发**：接口 `POST /users/login`，bcrypt.compare() 校验密码后签发：
- `token`（2小时）：含 id、role、is_root
- `refreshToken`（7天）：含 id

同时判断当日是否首次登录，是则写入 +5 积分流水。

```js
// 签发 token（Express/controllers/userController.js）
const token = jwt.sign(
  { id: user.id, role: user.role, is_root: user.is_root },
  secretKey, { expiresIn: '2h' }
);
const refreshToken = jwt.sign({ id: user.id }, secretKey, { expiresIn: '7d' });
```

**Token 自动刷新**：前端 Axios 响应拦截器检测到业务 401 时，自动用 refreshToken 调用 `POST /users/refresh` 换取新 token，更新 localStorage 与 Pinia 后重发原请求，全程用户无感。若 refreshToken 也过期则清除状态跳转登录页。

**找回密码**：① 提交账号获取脱敏邮箱 → ② 发送邮箱验证码（6位，5分钟有效）→ ③ 校验验证码后重置密码。

### 4.2.2 文章管理模块

**文章发布**：前端集成 WangEditor 富文本编辑器，图片上传调用 `POST /upload/JPG`，后端 Multer 处理后返回 URL 供编辑器插入。提交接口 `POST /articles/token`，后端校验权限后写入 wz_articles，标签经 findOrCreateByName 去重后写入 wz_article_tags。

**分页查询与搜索**：`GET /articles` 支持 page、pageSize、keyword、category_id、tag_id、year、month、status 多参数，核心 SQL：

```sql
SELECT * FROM wz_articles
WHERE status != 2
  AND (title LIKE '%kw%' OR summary LIKE '%kw%' OR content LIKE '%kw%')
  AND category_id = ?
  AND YEAR(created_at) = ? AND MONTH(created_at) = ?
ORDER BY status DESC, id DESC
LIMIT ? OFFSET ?
```

返回 `{ list, pagination: { page, pageSize, total, totalPages } }`。

**时间归档**：`GET /articles/archive` 按年月聚合，返回 `[{ month: '2024-03', count: 12 }, ...]`，前端归档页展示后点击按年月参数筛选文章列表。

**阅读量统计**：详情接口携带 `incrementView=1&source=internal/external`，后端分别累加站内/站外阅读计数字段。

### 4.2.3 评论系统模块

**发表与楼中楼**：`POST /comments` 接收 article_id、content、parent_id（可选）。有 parent_id 时为回复评论，前端递归组装评论树展示。

**敏感词过滤**：后端从 wz_otherswitch 读取敏感词配置，逐词构建正则替换为 `***`：

```js
const words = sensitiveConfig.split(',').map(w => w.trim()).filter(Boolean);
let filtered = content;
for (const word of words) {
  filtered = filtered.replace(new RegExp(word, 'gi'), '***');
}
```

**审核机制**：评论默认 status=0（待审核），前台仅展示 status=1 的评论，管理员在后台可批量设为通过（1）或屏蔽（2）。

### 4.2.4 权限控制模块

**后端鉴权中间件**（Express/app.js）：含 `/token` 路径的请求强制校验 JWT，解析 req.user 后判断角色：
- 管理员（is_root=1）或编辑（role=editor）：可访问所有后台接口
- 普通用户（role=user）：仅可访问 /likes/token、/favorites/token 及修改自身信息
- 其他情况返回 403

```js
const isAdminOrEditor = req.user.is_root === 1 || req.user.role === 'editor';
const isUserLike = req.user.role === 'user' && req.url.startsWith('/likes/token');
if (!isAdminOrEditor && !isUserLike && !isUserFavorite) {
  return res.json({ code: 403, message: '无权限进行此操作' });
}
```

**前端路由守卫**：Vue Router beforeEach 检查 Pinia 中的用户角色，非管理员/编辑访问 /dashboard 时跳转首页。编辑角色不显示用户管理和系统设置菜单项。

### 4.2.5 数据看板模块

**数据聚合**：`GET /dashboard/stats` 通过多条聚合 SQL 查询：
- 近7日新增用户：按 DATE(created_at) 分组计数
- 近7日发布文章：按 DATE(created_at) 分组计数
- 热门文章 Top10：分别按阅读/点赞/收藏/评论数排序取前10
- 流量来源：SUM(view_internal_count) 与 SUM(view_external_count)
- 数据概览：用户总数、文章总数、评论总数、点赞总数

**ECharts 可视化**：前端获取数据后初始化 ECharts 实例，用户增长与文章发布使用折线图（lineChart），热门文章使用数据表格，流量来源使用饼图或柱状图，图表支持鼠标悬停 tooltip 交互。

```js
// 折线图配置示例（Vue3 数据看板组件）
const option = {
  xAxis: { type: 'category', data: dates },
  yAxis: { type: 'value' },
  series: [{ data: counts, type: 'line', smooth: true }]
};
myChart.setOption(option);
```
