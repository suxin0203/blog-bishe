# 开发环境

本系统采用前后端分离架构，前端基于 Vue 3 + Vite 构建单页面应用，后端基于 Node.js + Express 提供 RESTful API，数据库选用 MySQL 开源数据库，使用 mysql2 驱动进行连接与参数化查询。系统开发与测试所采用的软硬件环境如表 4.1 所示。

**表 4.1 系统开发环境**

| 硬件环境 | 软件环境 |
|----------|----------|
| 处理器：Intel Core i5-13600KF（14 核 6P+8E，20 线程，Intel 7） | 操作系统：Windows 11 专业版 64 位（版本 22631.5472，23H2） |
| 内存：32GB DDR4（2×16GB，双通道） | 运行时：Node.js 14.17.0（或 16.x / 18.x LTS） |
| 显卡：AMD Radeon RX 9070 GRE 12GB GDDR6 | 数据库：MySQL 8.0 |
| 硬盘：Samsung SSD 980 1TB + KIOXIA EXCERIA G2 1TB（约 1.8TB SSD） | 后端框架：Express 4.16.x |
| 主板：Intel B760 芯片组 | 前端框架：Vue 3.2.x，构建工具：Vite 3.x |
| 显示器：27 英寸 2560×1440，210Hz | 浏览器：Chrome 90+ / Edge 90+（推荐 Chrome 120+） |
| — | 开发工具：Visual Studio Code 或 Cursor，Postman 10.x（接口调试） |

**说明**：后端服务通过 `node ./bin/www` 或 `nodemon ./bin/www` 启动，监听 8020 端口；前端开发时使用 `npm run dev` 启动 Vite 开发服务器（默认 5173 端口），生产环境将 Vue 构建产物部署至 Nginx 或静态托管，与后端 API 跨域访问。数据库需预先安装 MySQL 8.0 并执行项目提供的 SQL 脚本完成建表与初始化。
