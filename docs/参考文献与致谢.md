# 附录一 核心接口说明

文栈博客系统后端提供完整的 RESTful API，可通过 Swagger UI 在线查阅：`http://localhost:8020/api-docs`

以下列出主要接口摘要：

| 方法 | 路径 | 说明 | 是否需要登录 |
|------|------|------|-----------|
| POST | /users | 用户注册 | 否 |
| POST | /users/login | 用户登录 | 否 |
| POST | /users/refresh | 刷新 Token | 否 |
| GET | /users/captcha | 获取图形验证码 | 否 |
| POST | /users/forgot-password | 找回密码-获取脱敏邮箱 | 否 |
| POST | /users/reset-password | 重置密码 | 否 |
| GET | /articles | 文章列表（分页/搜索/筛选）| 否 |
| GET | /articles/:id | 文章详情 | 否 |
| GET | /articles/archive | 时间归档 | 否 |
| POST | /articles/token | 发布文章 | 是（管理员/编辑）|
| PUT | /articles/token/:id | 编辑文章 | 是（管理员/编辑）|
| DELETE | /articles/token/:id | 删除文章 | 是（管理员/编辑）|
| GET | /categories | 分类列表 | 否 |
| POST | /categories/token | 新增分类 | 是（管理员/编辑）|
| GET | /tags | 标签列表 | 否 |
| POST | /tags/token | 新增标签 | 是（管理员/编辑）|
| GET | /comments | 评论列表 | 否 |
| POST | /comments | 发表评论 | 是（登录用户）|
| PUT | /comments/token/:id | 审核评论 | 是（管理员/编辑）|
| POST | /likes/token | 点赞/取消点赞 | 是（登录用户）|
| POST | /favorites/token | 收藏/取消收藏 | 是（登录用户）|
| GET | /dashboard/stats | 看板统计数据 | 是（管理员/编辑）|
| GET | /otherswitch | 获取系统设置 | 否 |
| PUT | /otherswitch/token | 更新系统设置 | 是（管理员）|
| POST | /upload/JPG | 图片上传 | 是 |
| GET | /points/log | 积分流水 | 是（登录用户）|
| GET | /points/items | 积分商品列表 | 否 |
| POST | /points/orders/token | 积分兑换 | 是（登录用户）|
