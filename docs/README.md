## 📝 文档维护说明

### 文档分类

- **项目说明类**：项目整体功能介绍
- **技术设计类**：功能模块、系统核心技术、积分系统说明
- **专题设计类**：PC 扫码登录、小程序移植方案
- **技术分析类**：富文本转 Markdown 分析
- **辅助工具类**：系统架构图、页面原型

### 更新原则

- 功能变更时，同步更新"功能模块.md"
- 技术架构变更时，同步更新"系统核心技术.md"
- 接口变更时，同步更新"功能模块.md"和 Swagger 文档
- 新增专题功能时，考虑是否需要独立文档

### 避免重复

- 通用内容统一放在"项目整体功能介绍.md"
- 专题内容独立成文档，避免在多个文档中重复
- 文档间通过链接引用，不要复制粘贴
