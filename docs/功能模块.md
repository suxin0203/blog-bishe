## 文栈博客系统功能模块

基于项目实际路由与业务划分，系统功能模块如下。

---

### 1. 用户认证模块（/users）

- **验证码**：`GET /captcha` 获取算术验证码（num1 + num2），前端 MD5 答案后随登录/注册提交，后端一次性校验并删除。
- **注册**：`POST /register`，校验验证码、账号长度（≥4）、密码强度、邮箱格式与唯一性，bcrypt 哈希密码后写入 `wz_users`。
- **登录**：`POST /login`，校验验证码与账号密码，签发 2h 访问 Token 与 7d 刷新 Token，刷新 Token 写入用户表；支持可选 openid 绑定（微信）。
- **Token 刷新**：`POST /refresh`，用 refreshToken 换取新访问 Token，校验数据库中的 refreshToken 与类型。
- **当前用户**：`GET /me`（需登录），返回当前用户信息（脱敏密码）。
- **用户管理**：`GET/PUT/DELETE /token/:id` 用户列表、按 ID 查询、更新、删除；编辑仅能改自己部分字段，管理员可改角色/状态。
- **修改密码**：`POST /token/updatePassword`，校验原密码后 bcrypt 更新新密码。
- **找回密码**：`GET /forgot-email` 根据用户名返回脱敏邮箱；`POST /forgot-verify` 校验完整邮箱后下发 5 分钟有效 resetToken；`POST /forgot-reset` 凭 resetToken 设置新密码（当日错误次数限制）。
- **管理员添加用户**：`POST /token/admin-add-user`，仅 is_root=1 可调用，可设角色 editor/user，无需验证码。

---

### 2. 文章管理模块（/articles）

- **列表**：`GET /` 公开分页列表（支持关键词、分类、时间归档等）；`GET /token/list` 后台列表（编辑仅看自己，管理员看全部）。
- **详情**：`GET /:id` 单篇正文、分类、标签、作者等。
- **发布/更新/删除**：`POST /token/`、`PUT /token/:id`、`DELETE /token/:id`，需后台权限；支持正常/置顶/回收站状态。
- **恢复**：`PUT /token/:id/restore` 从回收站恢复。
- **阅读量**：`POST /:id/view`，支持 source=internal|external 区分站内/站外阅读统计。
- **排行榜**：`GET /top` 按阅读量等排序的热门文章。
- **归档**：`GET /archive` 按年月等维度归档数据供前端筛选。

---

### 3. 分类与标签模块（/categories、/tags）

- **分类**：`GET /` 全部分类；`POST/PUT/DELETE /token/:id` 增删改（需后台权限）。
- **标签**：`GET /` 全部标签；`POST/PUT/DELETE /token/:id` 增删改（需后台权限）。文章与标签通过 `wz_article_tags` 多对多关联。

---

### 4. 评论模块（/comments）

- **按文章查评论**：`GET /article/:articleId` 获取某文章下评论（含楼中楼结构）。
- **发表评论**：`POST /`，可选登录（带 token 时记录评论者），敏感词过滤后以待审核状态入库。
- **后台管理**：`GET /token/` 评论列表；`PUT/DELETE /token/:id` 审核状态更新、删除。

---

### 5. 点赞与收藏模块（/likes、/favorites）

- **点赞**：`POST /token/article/:articleId/toggle` 切换点赞状态；`GET /article/:articleId/check` 查询当前用户是否已点赞。
- **收藏**：`POST /token/article/:articleId/toggle` 切换收藏；`GET /token/list` 当前用户收藏列表；`GET /article/:articleId/check` 是否已收藏。  
与积分模块联动（如点赞/收藏可获得积分，依业务配置）。

---

### 6. 留言模块（/messages）

- **列表与发表**：`GET /` 留言列表；`POST /` 提交留言（可选登录）。
- **后台管理**：`PUT/DELETE /token/:id` 更新状态或删除。

---

### 7. 积分与商城模块（/points）

- **商品**：`GET /goods`、`GET /goods/:id` 商品列表与详情；`POST/PUT/DELETE /token/goods[/:id]` 商品增删改（后台）。
- **订单**：`GET /orders`、`GET /orders/:id` 订单列表与详情；`POST /orders` 用户下单扣积分；`PUT /token/orders/:id` 后台更新订单状态。
- **积分流水**：`GET /log` 当前用户积分变动记录（如每日登录、点赞、兑换等）。

---

### 8. 数据看板模块（/dashboard）

- 需后台权限（管理员/编辑）：`GET /token/stats` 概览统计；`GET /token/article-rank` 文章排行；`GET /token/user-trend`、`GET /token/article-trend` 用户与文章趋势；`GET /token/traffic-source` 站内/站外流量来源。供前端 ECharts 等图表展示。

---

### 9. 系统设置模块（/otherswitch）

- **站点配置**：`GET /` 获取全部配置项（站点名、描述、LOGO、主题、页脚、敏感词等）；`POST/PUT/DELETE /token/:id` 增删改（需后台权限）。

---

### 10. 轮播图模块（/swiper）

- **前台**：`GET /` 轮播列表。
- **后台**：`POST/PUT/DELETE /token/:id` 轮播增删改。

---

### 11. 友链模块（/friendslink）

- **前台**：`GET /` 友链列表。
- **后台**：`POST/PUT/DELETE /token/:link_id` 友链增删改。

---

### 12. 上传模块（/upload）

- **富文本图片**：`POST /token/rich_editor_upload` 富文本编辑器内图片上传，落盘至 `public/upload/`。
- **轮播图图片**：`POST /token/lbt_upload` 轮播图图片上传。
- **图片管理**：`GET /imglist` 图片列表；`DELETE /token/delimg` 删除图片（需鉴权）。

---

### 13. 微信登录模块（/wechat）

- **通过 code 换 openid**：`GET /openid/:code`，登录时可传 openid 与用户绑定。
- **通过 openid 取用户信息**：`GET /userinfo/:openid`，用于微信端拉取已绑定用户信息。

---

### 14. 活动与签到模块（/activity）

- **活动列表**：`GET /token/` 全部活动。
- **创建活动**：`POST /time` 创建活动。
- **签到**：`GET /sign/select` 签到选项；`POST /sign` 提交签到。

---

### 15. 工具模块（/utils）

- **二维码等**：`GET /` 获取二维码等通用工具接口（依业务使用）。

---

### 模块与路由对照简表

| 模块       | 路径前缀     | 核心能力简述                           |
|------------|--------------|----------------------------------------|
| 用户认证   | /users       | 验证码、注册、登录、刷新Token、用户CRUD、找回/修改密码、管理员添加用户 |
| 文章       | /articles    | 列表、详情、CRUD、阅读量、排行榜、归档 |
| 分类       | /categories  | 分类 CRUD                              |
| 标签       | /tags        | 标签 CRUD                              |
| 评论       | /comments    | 按文章查评论、发表、后台审核/删除      |
| 点赞       | /likes       | 点赞切换、是否已赞                     |
| 收藏       | /favorites   | 收藏切换、我的收藏、是否已收藏         |
| 留言       | /messages    | 留言列表、发表、后台管理               |
| 积分商城   | /points      | 商品、订单、积分流水                   |
| 数据看板   | /dashboard   | 统计、趋势、排行、流量来源             |
| 系统设置   | /otherswitch | 站点配置 CRUD                          |
| 轮播图     | /swiper      | 轮播 CRUD                              |
| 友链       | /friendslink | 友链 CRUD                              |
| 上传       | /upload      | 富文本图、轮播图上传及图片管理         |
| 微信登录   | /wechat      | openid、userinfo                       |
| 活动签到   | /activity    | 活动列表、创建、签到                   |
| 工具       | /utils       | 二维码等                               |

需登录或需后台权限的接口路径中包含 `/token`，由 Express 中间件统一校验 JWT 与角色（详见《系统核心技术》中的认证与 RBAC 说明）。
