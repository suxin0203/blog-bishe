# 文栈博客系统功能模块

> 本文档只回答一件事：**系统有哪些模块、每个模块负责什么、对应哪些核心接口。**

> - 如果你想看认证、安全、鉴权、请求链路，请看 `docs/系统核心技术.md`
> - 如果你想看微信小程序扫码登录的专题设计，请看 `docs/PC扫码微信小程序登录设计.md`

## 一、模块划分总览

文栈博客系统当前可拆分为 15 个核心模块：

1. 用户认证与用户管理
2. 文章管理
3. 分类管理
4. 标签管理
5. 评论系统
6. 点赞系统
7. 收藏系统
8. 留言模块
9. 积分商城
10. 数据看板
11. 系统设置
12. 轮播图管理
13. 友情链接
14. 上传模块
15. 微信登录 / 扫码登录 / 活动签到 / 工具接口

其中，凡是路径中包含 `/token` 的接口，默认属于**受保护接口**，会由后端统一执行 JWT 校验与角色权限判断。

## 二、用户认证与用户管理模块（`/users`）

### 模块作用

负责账号注册、登录、Token 刷新、找回密码、密码修改、当前用户信息获取，以及后台用户管理。

### 核心能力

- 图形验证码校验
- 用户注册
- 用户登录
- 刷新 Token
- 当前登录用户信息获取
- 找回密码
- 修改密码
- 管理员新增用户
- 用户列表、用户详情、用户编辑、用户删除

### 核心接口

| 接口 | 方法 | 说明 |
|------|------|------|
| `/users/captcha` | GET | 获取验证码 |
| `/users/register` | POST | 注册 |
| `/users/login` | POST | 登录 |
| `/users/refresh` | POST | 刷新访问 Token |
| `/users/me` | GET | 获取当前登录用户信息 |
| `/users/forgot-email` | GET | 找回密码时查询脱敏邮箱 |
| `/users/forgot-verify` | POST | 校验邮箱并生成重置凭证 |
| `/users/forgot-reset` | POST | 重置密码 |
| `/users/token/updatePassword` | POST | 登录后修改密码 |
| `/users/token/` | GET | 后台获取用户列表 |
| `/users/token/:id` | GET/PUT/DELETE | 获取、修改、删除指定用户 |
| `/users/token/admin-add-user` | POST | 管理员后台添加用户 |

## 三、文章管理模块（`/articles`）

### 模块作用

负责文章的前台展示、后台发布与维护，是博客系统的核心内容模块。

### 核心能力

- 文章公开列表
- 文章后台列表
- 文章详情
- 新增文章
- 编辑文章
- 删除文章
- 恢复文章
- 阅读量统计
- 热门文章排行
- 时间归档

### 核心接口

| 接口 | 方法 | 说明 |
|------|------|------|
| `/articles` | GET | 前台文章列表 |
| `/articles/top` | GET | 热门文章排行 |
| `/articles/archive` | GET | 文章归档 |
| `/articles/:id` | GET | 文章详情 |
| `/articles/token/list` | GET | 后台文章列表 |
| `/articles/token/` | POST | 新建文章 |
| `/articles/token/:id` | PUT | 编辑文章 |
| `/articles/token/:id` | DELETE | 删除文章 |
| `/articles/token/:id/restore` | PUT | 恢复文章 |
| `/articles/:id/view` | POST | 阅读量 +1 |

## 二十、角色与访问边界说明

### 1. 游客

可访问：
- 文章列表、文章详情
- 分类、标签、轮播图、友链、留言列表
- 评论列表
- 登录、注册、找回密码
- 微信登录基础接口与扫码登录入口接口

### 2. 普通用户（`role=user`）

除游客能力外，还可访问：
- 点赞 / 收藏接口
- 自己的资料修改接口
- 积分订单、积分流水等登录态能力
- 评论、留言等互动提交能力

### 3. 编辑 / 管理员

除普通用户能力外，还可访问：
- 后台文章管理
- 分类、标签管理
- 评论管理
- 留言管理
- 数据看板
- 积分商品与订单管理
- 上传、轮播、友链、系统设置等后台接口
