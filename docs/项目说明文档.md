## 1. 项目名称与简介

### 1.1 项目名称

**文栈博客系统（Wenzhan Blog）**

### 1.2 项目简介

文栈博客系统是一套基于 `Vue 3 + Express + MySQL` 构建的前后端分离博客平台。系统围绕“内容发布、用户互动、后台管理、运营分析”四条主线展开，当前已覆盖用户认证、文章管理、评论互动、分类标签、系统设置、数据看板、积分商城、微信登录以及 PC 扫微信小程序码登录等能力。

与传统仅支持文章 CRUD 的博客不同，文栈博客更强调：

- 多角色权限控制
- 内容运营与统计分析
- 登录安全与请求安全
- 积分与扩展业务能力
- Web 与微信小程序之间的登录联动

因此，该系统既适合个人博客，也适合小型团队或组织用于内容管理与展示。

## 2. 开发目的与应用场景

### 2.1 开发目的

本项目的开发目的主要包括以下几个方面：

1. 构建一个功能相对完整的博客系统，而不只是简单的信息展示站点。
2. 在博客场景下实践前后端分离、JWT 鉴权、RBAC 权限控制、文件上传、数据统计等常见工程能力。
3. 形成一套可用于课程设计、毕业设计、项目展示或个人作品集的综合系统。
4. 探索博客系统从“内容发布平台”向“互动与运营平台”延展的实现方式。

### 2.2 应用场景

该系统适用于以下场景：

- 个人技术博客或知识整理平台
- 小型团队的内容协作发布平台
- 带后台管理的数据展示型博客站点
- 需要积分激励、扫码登录等扩展能力的轻量级内容平台

## 4. 系统整体架构

### 4.1 前后端分离架构

系统采用前后端分离模式：

- 前端负责页面展示、交互逻辑、状态管理
- 后端负责 RESTful API、认证授权、业务处理、数据库读写
- MySQL 负责数据持久化

可概括为：

`前端 Vue 应用 -> HTTP 请求 -> Express 后端 -> MySQL 数据库`

### 4.2 后端分层结构

后端主要采用以下结构：

- `routes`：路由层，定义接口入口
- `controllers`：控制器层，接收请求并组织响应
- `services`：服务层，处理业务逻辑
- 数据访问层：执行 SQL 与数据读写

这种结构有利于：

- 功能拆分
- 逻辑复用
- 后续维护与扩展
- 统一鉴权与统一错误处理

## 6. 主要功能模块说明

为了避免与 `docs/功能模块.md` 重复，这里只做业务层概括，不展开所有接口。

### 6.1 用户模块

用户模块是系统认证入口，承担注册、登录、刷新登录态、找回密码、用户管理等职责，并为整套系统提供统一身份基础。

### 6.2 文章模块

文章模块是系统最核心的内容模块，支持前台展示与后台维护两种使用方式，构成博客系统的主体内容来源。

### 6.3 分类与标签模块

用于对文章进行结构化组织，使用户可以从主题与关键词两个维度对内容进行查找与归类。

### 6.4 评论、点赞、收藏与留言模块

这些模块共同构成用户互动体系，使博客不再只是静态阅读平台，而是具备参与感和反馈机制的内容社区。

### 6.5 积分商城模块

该模块将用户行为与激励机制结合起来，支持积分获取、商品兑换、订单处理与积分流水查询，提升系统扩展性。

### 6.6 数据看板模块

该模块用于将系统运行情况可视化，包括用户增长、文章发布趋势、热门内容排行与流量来源等数据，有助于后台运营分析。

### 6.7 微信与扫码登录模块

这是系统相对有特色的扩展模块。除了基础微信 `openid` 获取外，系统还支持 PC 端展示二维码、小程序端扫码确认并完成 Web 登录的跨端登录能力。

## 7. 典型业务流程概述

### 7.1 用户登录流程

1. 用户输入账号、密码与验证码
2. 前端提交登录请求
3. 后端校验验证码和密码
4. 登录成功后签发 Token 与 refreshToken
5. 前端保存登录态并进入系统

### 7.2 文章发布流程

1. 编辑或管理员登录后台
2. 进入文章编辑页面填写标题、内容、分类、标签等信息
3. 前端提交文章保存请求
4. 后端校验权限后写入数据库
5. 返回结果并刷新文章列表

### 7.3 文章互动流程

1. 用户浏览文章详情
2. 用户发表评论、点赞或收藏
3. 后端根据登录态和权限判断是否放行
4. 评论进入审核流，点赞与收藏直接记录
5. 前端刷新互动状态

### 7.4 扫码登录流程

1. PC 端创建扫码会话并展示小程序码
2. 用户使用微信小程序扫码
3. 小程序端根据 openid 判断是直接确认登录，还是进入注册 / 绑定流程
4. 后端更新扫码会话状态
5. PC 端轮询获取状态并完成登录

## 8. 系统特色与亮点

相较于一般课程型博客项目，文栈博客系统具备以下较明显的亮点：

### 8.1 权限体系较完整

不是单一管理员模型，而是引入了管理员、编辑、普通用户三类角色，形成更贴近真实业务的权限边界。

### 8.2 认证体系较完整

系统不是简单登录即完，而是加入了验证码、JWT、refreshToken、时间戳防重放等机制，安全性更强。

### 8.3 模块扩展性较强

除了博客基础模块外，还加入了数据看板、积分商城、活动签到、微信登录等能力，使系统更具综合性。

### 8.4 跨端登录设计有特色

PC 扫微信小程序码登录属于项目的差异化亮点，它把 Web 端、后端和微信小程序三方串联起来，具有较强展示价值。
