# 积分流水解析优化

## ✅ 已完成

### 参考 Vue3 前端逻辑

根据 `Vue3/src/views/MyPointsLog.vue` 和 `Users.vue` 的解析逻辑，统一了小程序的积分流水显示。

### 解析规则

```javascript
const reasonMap = {
  'daily_login': '每日登录',
  'comment': '评论通过',
  'like': '点赞',
  'like_cancel': '取消点赞',
  'article_liked': '文章获赞',
  'article_unliked': '文章取消获赞',
  'article_publish': '发布文章',
  'article_delete': '删除文章',
  'comment_approved': '评论审核通过',
  'comment_removed': '删除已通过评论',
  'redeem': '兑换',
  'redeem_goods': '积分兑换',
  'refund': '退款',
  'admin_adjust': '管理员调整'
}

// 文章相关操作，显示文章标题
const actionReasons = ['article_liked', 'article_unliked', 'article_publish', 'article_delete', 'comment_approved', 'comment_removed']

if (remark && actionReasons.includes(reason)) {
  return `${base}《${remark}》`  // 例如：文章获赞《Vue3 实战教程》
}

// 其他有备注的情况
return remark ? `${base}：${remark}` : base
```
