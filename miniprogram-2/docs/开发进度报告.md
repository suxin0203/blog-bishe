## 🎯 核心功能实现细节

### 积分商城流程

```
用户浏览商城
  ↓
选择商品查看详情
  ↓
选择数量
  ↓
[实物商品] 填写收货信息
  ↓
确认兑换（积分检查、库存检查）
  ↓
创建订单
  ↓
跳转到订单列表
```

### 搜索功能流程

```
用户进入搜索页
  ↓
查看搜索历史/热门搜索
  ↓
输入关键词或点击推荐
  ↓
执行搜索
  ↓
展示搜索结果
  ↓
上拉加载更多
  ↓
点击文章查看详情
```

## 🔧 技术实现要点

### 1. 接口对接
- 所有接口已在 `api/index.js` 中封装
- 使用 `utils/request.js` 统一处理请求
- 自动携带 Token 认证
- Token 过期自动刷新

### 2. 数据处理
- 图片 URL 使用 `util.convertImageUrl()` 转换
- 时间格式使用 `util.formatTime()` 处理
- 积分原因使用 `util.parsePointsReason()` 解析

### 3. 用户体验
- 下拉刷新、上拉加载
- 加载状态提示
- 空状态展示
- 错误提示
- 二次确认

### 4. 样式设计
- 渐变背景（积分相关页面）
- 卡片式布局
- 网格布局（商品、功能特性）
- 响应式设计
- 统一圆角和阴影
