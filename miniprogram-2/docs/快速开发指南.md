# 微信小程序开发快速指南

## 🚀 快速开始

### 1. 环境准备
- 安装微信开发者工具
- 获取小程序 AppID

### 2. 配置后端地址
编辑 `utils/config.js`：
```javascript
module.exports = {
  baseURL: 'http://localhost:8021',  // 开发环境
  // baseURL: 'https://wzapi.suxin23.cn',  // 生产环境
  appId: 'your-appid'
}
```

### 3. 导入项目
1. 打开微信开发者工具
2. 导入 `miniprogram-2` 目录
3. 填入 AppID
4. 点击编译运行

## 🔌 后端接口依赖

### 必需接口
```javascript
// 文章
GET /articles                    # 文章列表
GET /articles/top                # 热门文章
GET /articles/:id                # 文章详情
POST /articles/:id/view          # 增加阅读量

// 用户
GET /users/me                    # 当前用户
POST /users/login                # 登录
POST /users/register             # 注册
POST /users/refresh              # 刷新Token

// 积分
GET /points/token/log            # 积分流水
GET /points/goods                # 商品列表 ⭐
GET /points/goods/:id            # 商品详情 ⭐
POST /points/orders              # 创建订单 ⭐
GET /points/orders               # 订单列表 ⭐

// 互动
POST /likes/token/article/:id/toggle      # 点赞
POST /favorites/token/article/:id/toggle  # 收藏
POST /comments                            # 评论
GET /comments/article/:id                 # 评论列表

// 微信
GET /wechat/openid/:code         # 获取openid
GET /wechat/userinfo/:openid     # 查询绑定用户
```

## 📦 新增功能使用说明

### 1. 积分商城

#### 商品列表
- 路径：`/pages/points/mall`
- 功能：浏览商品、分类筛选、查看库存
- 入口：积分首页 → 积分商城

#### 商品详情
- 路径：`/pages/points/goods-detail?id=xxx`
- 功能：查看商品详情、选择数量、填写地址、兑换下单
- 验证：积分充足性、库存检查、手机号格式

#### 我的订单
- 路径：`/pages/points/orders`
- 功能：查看订单列表、筛选状态
- 入口：积分商城 → 我的订单 / 我的页面 → 我的订单

### 2. 文章搜索

#### 搜索页面
- 路径：`/pages/search/index`
- 功能：关键词搜索、搜索历史、热门推荐
- 入口：首页 → 搜索框

#### 搜索历史
- 存储：本地 Storage
- 容量：最多保存 20 条
- 操作：点击快速搜索、清空历史

### 3. 积分规则
- 路径：`/pages/points/rules`
- 内容：获取积分、消耗积分、扣除积分、温馨提示
- 入口：积分首页 → 积分规则 / 我的页面 → 积分规则

### 4. 关于页面
- 路径：`/pages/about/index`
- 内容：应用信息、功能特性、联系方式、更新日志
- 入口：我的页面 → 关于系统

## 🐛 常见问题

### 1. 图片不显示
- 检查 `config.js` 中的 `baseURL`
- 确保图片域名在合法域名列表
- 开发阶段勾选"不校验合法域名"

### 2. 接口请求失败
- 检查后端服务是否启动
- 检查 `baseURL` 配置是否正确
- 查看控制台网络请求日志

### 3. Token 过期
- 自动刷新机制已实现
- 刷新失败会跳转登录页
- 检查 `refreshToken` 是否有效

### 4. 商品兑换失败
- 检查积分是否充足
- 检查商品库存
- 实物商品需填写完整收货信息
- 手机号格式需正确
