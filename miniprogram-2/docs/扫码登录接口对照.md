## ✅ 接口参数和返回值

### 1. miniappEntry（小程序入口）

**请求：**
```javascript
POST /qr-login/entry
{
  sceneId: "uuid",
  code: "wx_code"  // 微信登录 code
}
```

**返回 - 已绑定：**
```javascript
{
  code: 200,
  message: "已确认登录",
  data: {
    action: "login_ok"
  }
}
```

**返回 - 未绑定：**
```javascript
{
  code: 200,
  message: "需要注册或绑定账号",
```

**返回 - 过期：**
```javascript
{
  code: 410,
  message: "二维码已过期，请刷新PC页面重新扫码",
  data: {
    status: "expired"
  }
}
```

## ✅ 小程序逻辑流程

### pages/qr-login/index.js

```javascript
onLoad(options) {
  // 1. 获取 sceneId
  const { scene, sceneId } = options
  let finalSceneId = scene ? decodeURIComponent(scene) : sceneId
  
  // 2. 检查登录状态
  if (!auth.isLoggedIn()) {
    this.showLoginPrompt()  // 提示去登录
    return
  }
  
  // 3. 调用小程序入口
  this.handleMiniappEntry()
}

async handleMiniappEntry() {
  // 1. 获取微信 code
  const loginRes = await wx.login()
  const code = loginRes.code
  
  // 2. 调用后端接口
  const res = await api.qrLogin.miniappEntry({
    sceneId: this.data.sceneId,
    code
  })
  
  // 3. 处理返回结果
  if (res.action === 'login_ok') {
    // 已绑定，自动确认成功
    wx.showToast({ title: '确认成功' })
    wx.navigateBack()
  } else if (res.action === 'need_register_or_bind') {
    // 未绑定，提示去绑定
    this.setData({
      needBind: true,
      bindToken: res.bindToken
    })
    this.showBindPrompt()
  }
}

showBindPrompt() {
  wx.showModal({
    title: '需要绑定账号',
    content: '当前微信未绑定账号，请选择注册新账号或绑定已有账号',
    success: (res) => {
      if (res.confirm) {
        // 跳转到登录页面，携带参数
        wx.redirectTo({
          url: `/pages/auth/login?mode=bind&sceneId=${this.data.sceneId}&bindToken=${this.data.bindToken}`
        })
      }
    }
  })
}
```

## ✅ 后端逻辑流程

### qrLoginController.miniappEntry

```javascript
1. 接收 sceneId 和 code
2. 查询会话是否存在
3. 检查会话是否过期
4. 调用微信接口获取 openid
5. 查询数据库是否已绑定
   - 已绑定：更新会话状态为 confirmed，返回 login_ok
   - 未绑定：生成 bindToken，返回 need_register_or_bind
```
