## 前端显示逻辑

### 小程序解析函数

```javascript
parseReason(reason, remark) {
  const reasonMap = {
    'daily_login': '每日登录',
    'comment': '评论通过',
    'like': '点赞',
    'like_cancel': '取消点赞',
    'article_liked': '文章获赞',
    'article_unliked': '文章取消获赞',
    'article_publish': '发布文章',
    'article_delete': '删除文章',
    'comment_approved': '评论审核通过',
    'comment_removed': '删除已通过评论',
    'redeem': '兑换',
    'redeem_goods': '积分兑换',
    'refund': '退款',
    'admin_adjust': '管理员调整'
  }
  
  const base = reasonMap[reason] || reason || '未知原因'
  
  // 文章相关操作，显示文章标题
  const actionReasons = ['article_liked', 'article_unliked', 'article_publish', 'article_delete', 'comment_approved', 'comment_removed']
  if (remark && actionReasons.includes(reason)) {
    return `${base}《${remark}》`
  }
  
  // 其他有备注的情况
  return remark ? `${base}：${remark}` : base
}
```

### WXML 调用

```xml
<!-- 积分首页 -->
<text class="log-reason">{{parseReason(item.reason, item.remark)}}</text>

<!-- 积分流水页 -->
<text class="log-reason">{{parseReason(item.reason, item.remark)}}</text>
```

## 与 Vue3 前端对比

### Vue3 实现
```javascript
const pointReasonLabel = (item) => {
  const map = { /* 同样的映射 */ };
  const base = map[item.reason] || item.reason || "未知原因";
  const actionReasons = new Set(["article_liked", "article_unliked", "article_publish", "article_delete", "comment_approved", "comment_removed"]);
  if (item.remark && actionReasons.has(item.reason)) return `${base}《${item.remark}》`;
  return item.remark ? `${base}：${item.remark}` : base;
};
```

### 小程序实现
```javascript
parseReason(reason, remark) {
  const reasonMap = { /* 同样的映射 */ };
  const base = reasonMap[reason] || reason || '未知原因';

  if (remark && actionReasons.includes(reason)) {
    return `${base}《${remark}》`;
  }
  return remark ? `${base}：${remark}` : base;
}
```

## 可能的问题排查

### 问题1：显示为 "未知原因"
**原因：** `reason` 字段不在 `reasonMap` 中
**解决：** 检查后端返回的 `reason` 值，添加到 `reasonMap`

### 问题2：remark 没有显示
**原因：** 后端没有正确解析 `remark`
**解决：** 检查后端 `getPointsLogList` 函数的正则匹配

### 问题3：显示格式不对
**原因：** WXML 调用时参数顺序错误
**解决：** 确保调用 `parseReason(item.reason, item.remark)`
