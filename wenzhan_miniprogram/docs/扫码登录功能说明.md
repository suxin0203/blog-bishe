### 2. **扫码登录流程**

#### 流程说明：
1. **PC 端生成二维码**
   - 调用 `POST /qr-login/session` 创建会话
   - 获取小程序码（包含 sceneId）
   - 轮询 `GET /qr-login/session/:sceneId` 查询状态

2. **用户扫码**
   - 小程序打开 `pages/qr-login/index`
   - 自动调用 `POST /qr-login/miniapp-entry`
   - 传递 `sceneId` 和微信 `code`

3. **后端判断**
   - **已绑定**：返回 `action: 'login_ok'`，自动确认登录
   - **未绑定**：返回 `action: 'need_register_or_bind'` 和 `bindToken`

4. **绑定账号**（如果需要）
   - 跳转到登录页面，携带 `sceneId` 和 `bindToken`
   - 用户选择注册或绑定已有账号
   - 调用对应接口完成绑定

5. **PC 端获取 Token**
   - 轮询检测到 `status: 'confirmed'`
   - 获取 `token` 和用户信息
   - 完成登录

## 🎯 接口说明

### 小程序端接口

#### 1. 小程序入口
```javascript
POST /qr-login/miniapp-entry
{
  sceneId: "uuid",
  code: "wx_code"
}

// 返回 - 已绑定
{
  code: 200,
  data: {
    action: "login_ok"
  }
}

// 返回 - 未绑定
{
  code: 200,
  data: {
    action: "need_register_or_bind",
    bindToken: "uuid"
  }
}
```

#### 2. 注册并确认
```javascript
POST /qr-login/miniapp-register-and-confirm
{
  sceneId: "uuid",
  bindToken: "uuid",
  username: "test",
  password: "123456",
  email: "test@example.com"
}
```

#### 3. 绑定并确认
```javascript
POST /qr-login/miniapp-bind-and-confirm
{
  sceneId: "uuid",
  bindToken: "uuid",
  username: "existing_user",
  password: "password"
}
```

## 🔒 安全机制

1. **不携带 Token**
   - 二维码只包含 sceneId
   - 不包含任何敏感信息

2. **会话过期**
   - 5 分钟有效期
   - 过期自动失效

3. **一次性使用**
   - 确认后会话状态变为 completed
   - 无法重复使用

4. **绑定 Token**
   - 未绑定用户需要 bindToken
   - bindToken 5 分钟有效期
   - 防止中间人攻击
