## 🚀 快速开始

### 1. 配置后端 API

编辑 `utils/config.js`：
```javascript
module.exports = {
  baseURL: 'http://localhost:3000',  // 修改为你的后端地址
  timeout: 10000
}
```

### 2. 导入项目

1. 打开微信开发者工具
2. 导入项目，选择 `miniprogram-2` 目录
3. 填写 AppID（测试可用测试号）

### 3. 启动后端服务

```bash
cd Express
npm install
npm start
```

### 4. 运行小程序

点击微信开发者工具的"编译"按钮

## 📝 开发建议

### 代码规范

- 使用 ES6+ 语法
- 统一使用 Promise 处理异步
- 组件化开发，提高复用性

### 调试技巧

- 使用 `console.log` 查看数据
- 使用微信开发者工具的调试器
- 查看 Network 面板检查接口调用
