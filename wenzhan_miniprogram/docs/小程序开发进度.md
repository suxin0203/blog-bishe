## API 接口封装情况

### 已封装的接口模块

所有接口已在 `api/index.js` 中完整封装：

1. **article** - 文章相关（11个接口）
   - 列表、详情、热门、归档、创建、更新、删除、恢复、阅读量

2. **category** - 分类相关（4个接口）
   - 列表、创建、更新、删除

3. **tag** - 标签相关（4个接口）
   - 列表、创建、更新、删除

4. **swiper** - 轮播图相关（4个接口）
   - 列表、创建、更新、删除

5. **comment** - 评论相关（5个接口）
   - 列表、创建、更新、删除、按文章查询

6. **like** - 点赞相关（2个接口）
   - 切换点赞、检查状态

7. **favorite** - 收藏相关（3个接口）
   - 切换收藏、检查状态、我的收藏

8. **message** - 留言相关（4个接口）
   - 列表、创建、更新、删除

9. **points** - 积分相关（10个接口）
   - 流水、商品列表、商品详情、创建订单、订单列表、订单详情等

10. **user** - 用户相关（12个接口）
    - 登录、注册、获取信息、修改密码、找回密码、用户管理等

11. **wechat** - 微信相关（3个接口）
    - 获取 openid、获取用户信息、绑定 openid

12. **qrLogin** - 扫码登录相关（5个接口）
    - 创建会话、查询状态、小程序入口、注册确认、绑定确认

13. **dashboard** - 数据看板（5个接口）
    - 统计概览、文章排行、用户趋势、文章趋势、流量来源

14. **system** - 系统配置（4个接口）
    - 获取配置、创建、更新、删除

15. **friendLink** - 友情链接（4个接口）
    - 列表、创建、更新、删除

16. **upload** - 文件上传（4个接口）
    - 富文本上传、轮播图上传、图片列表、删除图片

17. **activity** - 活动签到（4个接口）
    - 活动列表、创建活动、签到选项、提交签到

18. **utils** - 工具接口（1个接口）
    - 获取工具结果

19. **captcha** - 验证码（1个接口）
    - 获取验证码

**总计**：约 90+ 个接口已完整封装

## 开发建议

### 新功能开发流程

1. **查阅 API 文档**
   - 优先查看：`docs/API接口快速参考.md`
   - 详细参数：http://localhost:8021/api-docs
   - 快速索引：`../../docs/API接口索引.md`

2. **检查接口封装**
   - 查看 `api/index.js` 是否已封装
   - 如未封装，添加到对应模块

3. **创建页面**
   - 使用微信开发者工具创建页面
   - 参考现有页面结构

4. **实现功能**
   - 使用已封装的 API 接口
   - 使用 `utils/auth.js` 处理认证
   - 使用 `utils/util.js` 处理通用逻辑

5. **测试验证**
   - 测试正常流程
   - 测试异常情况
   - 测试未登录状态

### 代码规范

1. **命名规范**
   - 文件名：小写字母 + 连字符（如 `goods-detail.js`）
   - 变量名：驼峰命名（如 `userInfo`）
   - 常量名：大写字母 + 下划线（如 `API_BASE_URL`）

2. **注释规范**
   - 函数注释：说明功能、参数、返回值
   - 复杂逻辑：添加行内注释
   - 避免无意义注释

3. **错误处理**
   - 使用 try-catch 捕获异常
   - 统一错误提示
   - 记录错误日志
