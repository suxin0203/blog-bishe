# 小程序开发配置说明

## 一、后端 API 配置

### 1. 修改 API 基础地址

编辑 `utils/config.js` 文件：

```javascript
module.exports = {
  // 修改为你的后端 API 地址
  baseURL: 'http://localhost:3000',  // 开发环境
  // baseURL: 'https://wzapi.suxin23.cn',  // 生产环境
  
  // 微信小程序 AppID
  appId: 'your-appid',
  
  // 其他配置保持默认即可
}
```

### 2. 后端接口要求

确保后端已实现以下接口：

#### 文章相关
- `GET /articles` - 文章列表
- `GET /articles/top` - 热门文章
- `GET /articles/:id` - 文章详情
- `POST /articles/:id/view` - 增加阅读量
- `GET /categories` - 分类列表
- `GET /tags` - 标签列表
- `GET /swiper` - 轮播图

#### 用户认证
- `GET /wechat/openid/:code` - 获取 openid
- `GET /wechat/userinfo/:openid` - 查询绑定用户
- `POST /users/register` - 注册
- `POST /users/login` - 登录
- `GET /users/me` - 当前用户信息
- `POST /users/refresh` - 刷新 Token

#### 积分系统
- `GET /points/log` - 积分流水
- `GET /points/goods` - 商品列表
- `POST /points/orders` - 创建订单

#### 互动功能
- `GET /comments/article/:articleId` - 评论列表
- `POST /comments` - 发表评论
- `POST /likes/token/article/:articleId/toggle` - 点赞
- `GET /likes/article/:articleId/check` - 点赞状态
- `POST /favorites/token/article/:articleId/toggle` - 收藏
- `GET /favorites/token/list` - 收藏列表
- `GET /favorites/article/:articleId/check` - 收藏状态

#### 扫码登录
- `POST /miniapp/qr-login/entry` - 扫码入口
- `POST /miniapp/qr-login/register-and-confirm` - 注册并确认
- `POST /miniapp/qr-login/bind-and-confirm` - 绑定并确认

## 二、微信小程序配置

### 1. 获取 AppID

1. 登录[微信公众平台](https://mp.weixin.qq.com/)
2. 进入"开发" -> "开发管理" -> "开发设置"
3. 复制 AppID 和 AppSecret

### 2. 配置服务器域名

在微信公众平台后台配置：

**开发** -> **开发管理** -> **开发设置** -> **服务器域名**

需要配置以下域名（替换为你的实际域名）：

- **request 合法域名**：`https://api.yourdomain.com`
- **uploadFile 合法域名**：`https://api.yourdomain.com`
- **downloadFile 合法域名**：`https://api.yourdomain.com`

**注意**：
- 域名必须使用 HTTPS
- 域名需要备案
- 开发阶段可以勾选"不校验合法域名"

### 3. 配置业务域名

如果需要在小程序内打开网页，需要配置业务域名：

**开发** -> **开发管理** -> **开发设置** -> **业务域名**

### 4. 修改项目配置

编辑 `project.config.json`：

```json
{
  "appid": "your-appid",  // 修改为你的 AppID
  "projectname": "文栈博客小程序",
  "setting": {
    "es6": true,
    "postcss": true,
    "minified": true
  }
}
```

## 三、后端 CORS 配置

确保后端已配置 CORS，允许小程序域名访问：

```javascript
// Express 示例
const cors = require('cors')

app.use(cors({
  origin: '*',  // 生产环境建议配置具体域名
  credentials: true
}))
```

## 四、微信登录配置

### 1. 后端配置微信 AppSecret

在后端配置文件中添加：

```javascript
module.exports = {
  wechat: {
    appId: 'your-appid',
    appSecret: 'your-appsecret'
  }
}
```

### 2. 实现 code 换 openid 接口

后端需要实现 `/wechat/openid/:code` 接口：

```javascript
router.get('/wechat/openid/:code', async (req, res) => {
  const { code } = req.params
  
  // 调用微信接口换取 openid
  const url = `https://api.weixin.qq.com/sns/jscode2session?appid=${appId}&secret=${appSecret}&js_code=${code}&grant_type=authorization_code`
  
  const response = await axios.get(url)
  const { openid, session_key } = response.data
  
  res.json({
    code: 0,
    data: { openid, session_key }
  })
})
```

## 六、常见问题

### 1. request:fail url not in domain list

**原因**：请求的域名不在合法域名列表中

**解决**：
- 开发阶段：勾选"不校验合法域名"
- 生产环境：在微信公众平台配置合法域名

### 2. 登录失败：errcode 40029

**原因**：code 无效或已使用

**解决**：
- code 只能使用一次
- 确保每次登录都调用 wx.login 获取新 code

### 3. Token 过期

**原因**：Token 有效期已过

**解决**：
- 使用 refreshToken 刷新
- 刷新失败则重新登录

### 4. 图片不显示

**原因**：图片域名不在合法域名列表中

**解决**：
- 配置 downloadFile 合法域名
- 或使用 HTTPS 图片地址

### 5. 上传文件失败

**原因**：上传域名不在合法域名列表中

**解决**：
- 配置 uploadFile 合法域名
- 检查后端上传接口

## 七、性能优化

### 1. 图片优化

- 使用 WebP 格式
- 压缩图片大小
- 使用 CDN 加速
- 懒加载图片

### 2. 请求优化

- 合并请求
- 使用缓存
- 减少请求次数
- 使用分页加载

### 3. 渲染优化

- 使用 setData 优化
- 避免频繁 setData
- 使用虚拟列表
- 减少 WXML 层级

## 八、发布上线

### 1. 代码审核

1. 在微信开发者工具中点击"上传"
2. 填写版本号和项目备注
3. 登录微信公众平台提交审核
4. 等待审核通过（一般 1-7 天）

### 2. 发布版本

审核通过后：

1. 登录微信公众平台
2. 进入"版本管理"
3. 点击"发布"
4. 用户即可使用新版本

### 3. 注意事项

- 确保所有功能正常
- 确保合法域名已配置
- 确保内容合规
- 准备好隐私政策
