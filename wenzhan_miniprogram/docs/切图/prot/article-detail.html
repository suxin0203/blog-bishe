小程序端如何复用现有博客 API

苏新2026-05-13阅读 756
文章封面图

文栈博客小程序端不需要重写后端，可以复用现有 Express RESTful API。核心工作在于请求封装、登录态管理和移动端页面体验。

一、请求封装

小程序请求层统一处理 baseURL、Authorization、X-Request-Time 和错误提示。当接口返回 401 时，可通过 refreshToken 进行刷新。

wx.request({\n url: baseURL + '/articles',\n header: { Authorization: 'Bearer ' + token }\n})

二、文章渲染

当前文章内容以 HTML 为主，MVP 阶段可以先兼容 rich-text；后续建议迁移到 Markdown，提高小程序端渲染稳定性。
